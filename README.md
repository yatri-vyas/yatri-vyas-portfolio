# yatri-vyas-portfolio

A personal portfolio website for Yatri Vyas, a BCA student and full-stack developer.

## Features

- Responsive portfolio website
- Light, modern user interface
- Skills and technologies section
- Project cards with project images
- Project-detail popup with GitHub and live links
- Education and experience timeline
- Contact section with GitHub and LinkedIn links
- Active navbar link while scrolling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Lucide Icons
- Google Fonts

## Projects Included

### Blog App
A full-stack blog application built using React, Vite, and Express.js REST API.

### Employee Management System
An employee-management REST API with authentication, CRUD operations, search, sorting, and pagination.

### Dusty Go Sparkle
A PHP and MySQL home-cleaning service booking application created as a BCA final-year project.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `portfolio.html` in any web browser.
